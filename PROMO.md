# FITKNOW · запуск мини-продукта

## Публичная версия

FITKNOW — бесплатный веб-органайзер тренировок, питания, добавок и анализов. Данные хранятся локально в браузере; импорт TXT/MD/CSV/JSON и экспорт резервной копии доступны из интерфейса приложения.

- GitHub Pages после настройки: https://setelite.github.io/FITKNOW/
- Посадочная страница после загрузки на хостинг: https://gornostaevmarketing.ru/fitknow/
- Воронка запуска: Instagram Reels (ключевое слово «ФИТ») → авто-DM Manychat → Telegram → посадочная страница → приложение.

## Что обязательно завершить

1. Сделать этот репозиторий Public, если планируется бесплатный GitHub Pages.
2. В Settings → Pages выбрать Deploy from a branch / main / root.
3. Опубликовать готовую папку `fitknow` в корне gornostaevmarketing.ru.
4. В `FITKNOW_CONFIG` посадочной страницы вписать реальные ссылки Instagram и Telegram. Пустые ссылки скрыты.
5. Настроить Instagram comment-to-DM и проверить первые тестовые комментарии через Manychat.

Важно: публичный URL не защищён условием подписки. Для доступа только по оплате или индивидуальной ссылке потребуется отдельная серверная авторизация.

Личная версия с медицинскими записями не должна попадать в этот репозиторий.
